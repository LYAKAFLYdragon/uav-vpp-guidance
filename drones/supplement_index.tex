\section*{Software and Data Availability}

The complete source code, training pipelines, and evaluation harness are available as a Git repository. Upon acceptance, the repository URL and commit hash will be disclosed in the final de-anonymized version. The repository includes:

\begin{itemize}
    \item UAV VPP Guidance environment (Python package with JSBSim backend)
    \item Training scripts for PPO high-level policy and low-level specialist freezing
    \item Evaluation pipeline with run manifest generation and artifact contract validation
    \item Configuration templates for reproducible evaluation snapshots
    \item Authoritative artifact index identifying the exclusive source of headline results and the scope of each supporting evidence stratum
    \item RQ1 crossing evidence synthesis: independent geometry envelope, all three valid PPO seeds, and source data for Figure S3
\end{itemize}
