This section reports the evidence currently available in the repository after the second revision round and separates completed formal runs from experiments that still require new checkpoints. The distinction is intentional. The paper's contribution is an auditable comparison protocol, so results that do not satisfy the frozen protocol are not treated as conclusive.

\subsection{Auditable fair-comparison protocol}\label{sec:fair_protocol}

The final comparison protocol is defined by the following reproducible clauses.

\begin{enumerate}
    \item \textbf{Observation space:} all learned methods use the same 16-dimensional normalized observation vector produced by \texttt{src/uav\_vpp\_guidance/envs/observation.py}; VPP-specific diagnostic variables are logged but not added unless explicitly stated as an ablation.
    \item \textbf{Training scaffold:} PPO is the shared optimizer. The target full-budget matrix uses the same MLP scale and reward definition for hierarchical VPP, zero-offset No-VPP, and the end-to-end RL baseline. Existing repository configurations are currently at 200k--300k PPO steps; the requested final matrix extends E2E to 2M steps and fixes VPP/No-VPP budgets before claims are promoted from exploratory to main-table status.
    \item \textbf{Random seeds:} the main table is frozen at 10 independent training seeds when checkpoints are available. The current repository contains 30 evaluation seeds on the simple backend and 10 evaluation seeds on a corrected JSBSim regression run, but it does not yet contain a completed 10-training-seed JSBSim VPP/No-VPP/E2E matrix.
    \item \textbf{Simulator backend:} simple point-mass results are used for mechanism isolation; Defence Technology main claims require JSBSim F-16 evaluation.
    \item \textbf{Metrics:} every method is evaluated by success rate, crash rate, timeout/out-of-bounds rate, mean return, standard deviation, 95\% confidence interval, effect size, and an exact binary-outcome test when applicable.
\end{enumerate}

This protocol follows the reporting concerns raised for deep-RL experiments by Henderson et al.~\cite{henderson2018deep} and Patterson et al.~\cite{patterson2023empirical}. Results below are labeled according to whether they satisfy the protocol. The current manuscript uses three evidence levels: the historical JSBSim fair-comparison matrix uses 5 VPP/No-VPP training seeds and 20 evaluation episodes per seed--scenario combination; the new external-baseline matrix uses 3 evaluation seeds, 10 episodes per seed, and four scenarios for pure pursuit, pure PN, APN1971, and a VPP reference; the new interface-ablation subset uses the same 3-seed evaluation protocol for full VPP, zero-offset No-VPP, and target-state-direct guidance. The latter two matrices are formal evaluation runs, but they do not replace the still-missing 10-training-seed JSBSim main matrix.

\subsection{External baselines and robustness experiments}\label{sec:external_and_robustness}

The repository evidence already shows why external guidance baselines cannot be omitted: pure PN without VPP succeeds in selected high-energy tail-chase candidates where several VPP-based variants fail. The completed external-baseline matrix evaluates pure pursuit, pure PN, APN1971, and a VPP reference under the same feasible-geometry scenarios, metric schema, and 3-seed evaluation budget (Fig.~\ref{fig:external_baselines}). All four methods achieve 90/120 successes (75.0\%, Wilson 95\% CI: 66.6--81.9\%). As in the ablation subset, favorable, neutral, and challenging scenarios are solved by all methods, while the disadvantage scenario fails for all methods by out-of-bounds termination. Fisher exact tests against the VPP reference are therefore non-significant for terminal success ($p=1.0$). Paired return tests show lower returns for the classical baselines relative to the VPP reference ($p=5.25\times10^{-9}$, Cohen's $d=-0.575$), with the difference concentrated in the failed disadvantage episodes. APN1971 matches pure PN in this constant-velocity target suite because no nonzero target acceleration is exposed to the APN feed-forward term.

The formal episode matrices also show that the remaining terminal failures are not crash- or timeout-dominated in the frozen feasible-geometry suite.
